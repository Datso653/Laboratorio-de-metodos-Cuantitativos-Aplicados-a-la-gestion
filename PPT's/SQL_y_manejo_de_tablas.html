D · Resumir

GROUP BY: 201 filas se vuelven 5

Cada cuadradito es una venta. GROUP BY las junta por vendedor y las funciones (COUNT, SUM, AVG) resumen cada grupo en un solo número.

D · Resumir

Se escribe en un orden, se ejecuta en otro

Se escribeSELECTFROMWHEREGROUP BYHAVINGORDER BYLIMIT
Se ejecutaFROMWHEREGROUP BYHAVINGSELECTORDER BYLIMIT

Por eso WHERE no puede usar SUM

Corre antes de armar los grupos: los totales todavía no existen. Para filtrar por un total está HAVING, que corre después.

Y por eso ORDER BY sí puede usar un alias

Corre después del SELECT, cuando el nombre facturacion ya existe.

G · Script y esquema

El esquema: el plano de la base

Una base no se arma a mano: se arma corriendo un script, un archivo con instrucciones en orden. Así queda escrita y cualquiera la puede rearmar igual.

PRIMARY KEYPK

Identifica cada fila. Sin esto, la misma venta puede quedar cargada dos veces.

REFERENCESFK

Conecta con otra tabla: es lo que hace posible el JOIN.

NOT NULLNN: la base rechaza el dato malo

✗ NOT NULL constraint failed: ventas.importe

En una planilla cualquiera escribe cualquier cosa. En una base con buen esquema, el dato inconsistente ni siquiera entra.
